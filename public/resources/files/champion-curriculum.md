# Champion training curriculum

Four 60-minute sessions over two weeks. Each ends with homework that champions bring back to the next session.

## Session 1: Core workflows

- Projects, sessions, locations and modes.
- Issue to pull request with Plan mode.
- Parallel sessions in separate working trees.
- **Homework:** run three sessions on real work and note one thing that surprised you.

## Session 2: Making repositories agent-ready

- Writing project instructions that capture conventions.
- `.github/github-app.yml`: Setup and Run scripts, `server_ready_pattern`, review and trust.
- Sandbox defaults and when to use a cloud sandbox.
- **Homework:** open a pull request that adds a reviewed configuration file to one team repository.

## Session 3: Automations, canvases and connectors

- Scheduled and on-demand automations. Choosing the smallest tool set.
- Canvases: editor, browser, terminal and Office documents.
- Connectors and MCP servers on the approved list, and how to request a new one.
- Agent merge for shepherding pull requests.
- **Homework:** create one automation your team will read every week.

## Session 4: Running adoption on your team

- Running a 20-minute team demo.
- Answering first-line questions with the FAQ.
- Reporting patterns, crashes and blockers back to the CoE.
- Adding prompts to the shared library with deep links.
- **Homework:** run your team demo and post the recording.

## Champion commitments

- 2 to 4 hours a week.
- Attend the champion sync every two weeks.
- Keep your team's prompts and configuration current.
